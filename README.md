# Проект "Маски для банков"

## Описание:

Проект "Маски для банков" — это Python-приложение для обработки банковских операций. Он предоставляет два основных инструмента для работы с данными:

- **`filter_by_state`** — фильтрация операций по статусу (например, `EXECUTED` или `CANCELED`).
- **`sort_by_date`** — сортировка операций по дате (по возрастанию или убыванию).

Проект полезен для анализа банковских транзакций, подготовки отчётов и интеграции с другими системами.
