# Проект "Маски для банков"

## Описание:

Проект "Маски для банков" - это приложение для создания масок счетов или карт
Он включает в себя два основных инструмента:
- **Фильтрация операций по статусу** (filter_by_state)
- **Сортировка операций по дате** (sort_by_date)

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Alexandr01031999/my-project.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Запустите программу:
```
python widget.py
```
2. Следуйте инструкции
